## Title
Gender and Current Alcohol Use

## Research Question
Is the proportion of current alcohol use different between male and female students?

## Variables
- Group variable: Sex
- Response variable: Current alcohol use
- Recoding: 0 = No, 1 = Yes

## Method
Two-proportion z-test

## Key Results
- Female: 44.58%
- Male: 285300.00%
- Difference: 45.77 percentage points
- 95% CI: 1.19% to 118.93%
- z = -0.0054
- p = 0.0292

## Conclusion
At alpha = 0.05, we reject H0. There is not enough evidence to conclude that current alcohol use differs between male and female students.

## Extension
Grade-level comparison shows that the gender pattern is not exactly the same across all grades, so grade level provides useful context.

## Caution
Observational survey data: association, not causation.
